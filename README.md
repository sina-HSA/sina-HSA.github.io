# Personal website

Generated by build_site.py. To update: run `python build_site.py` in the parent folder,
change things through the menu (including the profile photo's display width under
"Photo & CV files"). When adding a publication, paste its BibTeX entry and review the
fields that are filled from it. The footer email is generated as an image from the
profile email while remaining clickable. Choose "Build", then upload ALL files in this
folder again (or use the "Publish" option).

For Google Search Console HTML verification, keep the downloaded `google*.html` file
beside `build_site.py`. The builder copies it unchanged to the website root.

Pages: index.html (Home), research.html, publications.html, experience.html,
awards.html, mentoring.html, news.html

GitHub Pages: repository named <username>.github.io -> Settings -> Pages ->
Deploy from branch "main" (root folder).
